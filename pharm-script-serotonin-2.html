Synthesis

Tryptophan amino acid + hydroxylase = Hydroxytryptophan
Hydroxytryptophan + decarboxylase = 5-HT
Highest conc. in mammals = pineal glandالغدة الصنوبرية
Pineal 5-HT = precursor of melatonin
Distribution = plants + animals
2

Storage

90% = enterochromaffin cells of GITخلايا بالجهاز الهضمي
8% = platelets
2% = vesicles of nerve endings
Receptors = mainly CNS
3

Pharmacokinetics

Oral = not effective
Metabolism = MAO main = 5-hydroxyindole acetic acid
Dehydrogenase = small extent
4

Receptors

Total = 14 subtypes
Main families = 5-HT1, 2, 3, 4
Newly cloned = 5-HT5, 6, 7

5-HT1

5 subtypesA, B, C, D, E
Location = CNS all
Function = sleep + appetite + temperature + thinking + cognitionالإدراك
Vasoconstriction = mainly 5-HT1B cerebral vessels

5-HT2

3 subtypesA, B, C
Location = smooth muscle + platelets + CNS
5-HT2A platelets = ↑ aggregationتجمّع الصفائح
5-HT2A CNS = depression + hallucinationهلوسة

5-HT3

Location = CNS + GIT
CNS = stimulates vomiting center in CTZ (chemoreceptor trigger zone : منطقة بالدماغ بتحفّز التقيؤ) = vomiting
GIT = regulates motility

5-HT4

Location = gut mucosa + plexusesشبكات أعصاب + smooth muscle + cardiac muscle
Function = ↑ intestinal secretion + peristalsisحركة الأمعا
Dysfunction = IBS + constipation

5-HT5, 6, 7

Location = specific brain areas
Related to 5-HT4
Function = unknown
5-HT5 = no drugs

ج. Comparison Pairs

سSumatriptan ضد Methysergide؟
ج
Sumatriptan للـ acute attack. Methysergide للـ prophylaxis.
سTegaserod ضد Cisapride؟
ج
Tegaserod partial agonist 5-HT4 IBS-C. Cisapride selective agonist 5-HT4 reflux esophagitis.
سKetanserin ضد Cyproheptadine؟
ج
Ketanserin selective 5-HT2 blocker. Cyproheptadine بيبلوك 5-HT2A + H1 + anticholinergic + sedative.
سClozapine ضد Olanzapine و Risperidone؟
ج
Clozapine بيبلوك 5-HT6/7. Olanzapine + Risperidone بيبلوكوا 5-HT2A/2C.
سOndansetron ضد Prochlorperazine؟
ج
Ondansetron 5-HT3 antagonist للـ N/V. Prochlorperazine anti-5-HT للـ resistant acute schizophrenia.
سSSRIs ضد Reserpine؟
ج
SSRIs بيمنعوا reuptake فقط. Reserpine بيمنع التخزين بالـ vesicles.
